# DevMind AI 🧠
### The All-in-One AI Platform for Developers

🔍 Code Review · 🐛 Bug Detection · 📚 Auto Documentation

## What is DevMind AI?
An AI-powered SaaS platform that helps developers:
- **CodeReview AI** — Auto reviews code, finds security issues & gives quality score
- **BugHunt AI** — Paste any error → Get root cause + fixed code instantly  
- **DevDocs AI** — Auto generates README, API docs & inline comments

## Supported Languages
Python, JavaScript, Java, C++, HTML/CSS
*(TypeScript, Go, Rust, PHP, Swift, Kotlin coming soon)*

## Tech Stack
- Frontend: React.js + Tailwind CSS
- Backend: FastAPI + Python
- AI Engine: Groq AI
- Database: PostgreSQL
